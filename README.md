# CodeAlpha_FlashcardQuizApp

## 📚 Description
A Flashcard Quiz App to help users study by creating and reviewing flashcards. Users can add custom cards, quiz themselves, and track their performance.

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- LocalStorage (for storing flashcards)

## 🚀 Features
- Add, edit, delete flashcards
- Quiz mode with score tracking
- Responsive design
